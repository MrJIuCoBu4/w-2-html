# Word 2 HTML

Локальный двухпанельный редактор: слева визуальный текст, справа живой HTML.
Вставляйте из Word или из веба, чистите разметку и копируйте готовый HTML —
полностью в браузере, без бэкенда.

**Репозиторий:** [github.com/MrJIuCoBu4/w-2-html](https://github.com/MrJIuCoBu4/w-2-html)

## Стек

- [Vite](https://vite.dev/) + React 19 + TypeScript
- [TipTap](https://tiptap.dev/) (ProseMirror) — визуальный редактор
- [CodeMirror 6](https://codemirror.net/) — панель HTML
- [js-beautify](https://github.com/beautify-web/js-beautify) — форматирование / минификация
- [react-icons](https://react-icons.github.io/react-icons/) (Font Awesome) — иконки тулбара

## Возможности

- **Синхронизация Visual ↔ HTML** с общей историей undo/redo между панелями
- **Тулбар**: жирный/курсив/подчёркивание/зачёркивание, цвета, шрифты, заголовки,
  выравнивание, списки (со стилями маркеров), отступы, межстрочный интервал,
  таблицы (сетка размеров + плавающий тулбар), ссылки, изображения, видео-вставки,
  горизонтальная линия, блок кода, цитата, спецсимволы, эмодзи, копирование HTML
- **Режимы вставки**: сохранить форматирование, очистить мусор Word или спросить
- **Инструменты кода**: поиск/замена, форматирование, сжатие, показ пробелов,
  размер шрифта, полноэкранная панель HTML
- **Раскладка**: равные панели, сворачивание любой стороны, компактный тулбар
  (More Text), мобильный предпросмотр, адаптивная вёрстка
- **Настройки**: режим вставки, единицы шрифта (px/pt), LTR/RTL, высота панели,
  опции CodeMirror, автосохранение, кодировка, полный HTML-документ при копировании,
  свой CSS и шрифты
- Настройки и черновик документа хранятся в `localStorage`

### Кодировка символов

Настройки → Экспорт → Кодировка символов:

| Режим | Поведение |
| ----- | --------- |
| **Named** | Западноевропейские буквы и символы → `&eacute;`, `&auml;`, `&copy;`, `&mdash;`, … Буквы без именованной сущности (кириллица, CJK, …) остаются UTF-8 — никогда `&#1092;`. |
| **Numeric** | Спецсимволы → `&#…;`. Все буквы остаются UTF-8. |
| **Raw UTF-8** | Без экранирования сущностями. |

## Установка

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (по умолчанию `http://localhost:5173/`).

## Скрипты

| Команда | Описание |
| ------- | -------- |
| `npm run dev` | Dev-сервер с HMR |
| `npm run build` | Проверка типов + production-сборка |
| `npm run check` | Линт + сборка (то, что гоняет CI) |
| `npm run preview` | Раздача сборки из `dist/` |
| `npm run lint` | Oxlint |
| `npm run test:e2e` | E2E-тесты Playwright (сами поднимают dev-сервер) |

## Тесты

```bash
npx playwright install chromium   # один раз
npm run test:e2e                   # прогон против dev-сервера
```

Покрытие: синхронизация Visual↔HTML, форматирование (марки, заголовки, списки,
отступы, цитаты, цвета), режимы вставки (Keep / Clean / Ask), очистка Word-разметки,
кодировки (named / numeric / raw), вставка (ссылка, изображение, видео, таблица,
спецсимволы), инструменты HTML (форматирование, сжатие, общая история undo/redo,
поиск и замена), раскладка панелей и сохранение в `localStorage`.

```
  lib/          настройки, синхронизация, очистка, списки, спецсимволы, кодировки…

tests/

```

## Примечания

- Всё работает на клиенте; подходит для офлайн-черновиков и приватной работы.
- Свой CSS в Настройки → Внешний вид применяется только к визуальному документу.
- Свои названия/URL шрифтов попадают в меню шрифтов (разделяйте через `#`).
